⏰ Amarella Alarm

Aplikasi kecil untuk tablet produksi. Saat outlet mengirim PO, tablet berbunyi alarm terus (suara khas Amarella, volume alarm, tetap bunyi walau tablet mode senyap) sampai ditekan HENTIKAN atau PO sudah diterima. Tetap jalan walau aplikasi Amarella ditutup.

⬇ Unduh Amarella Alarm (APK, 74 KB)

Khusus Android 8 ke atas. Versi 1.0.

1. Pasang

  1. Tekan tombol unduh di atas (di Chrome tablet produksi).
  2. Buka file amarella-alarm.apk dari notifikasi unduhan.
  3. Kalau muncul "tidak diizinkan memasang aplikasi dari sumber ini": tekan Setelan → aktifkan Izinkan dari sumber ini → kembali → Pasang / Install.
  4. Kalau muncul peringatan Play Protect ("aplikasi tidak dikenal"): tekan Detail lainnya → Tetap instal. Aplikasi ini buatan sendiri untuk Amarella, tidak dari Play Store.

2. Hubungkan

  1. Buka aplikasi Amarella (yang biasa) → login akun tablet produksi → menu PO dari outlet → ⏰ Hubungkan aplikasi alarm. Muncul kode 16 huruf.
  2. Buka Amarella Alarm → ketik kodenya → tekan MULAI. Kalau diminta izin notifikasi, pilih Izinkan.
  3. Tekan Izinkan tetap jalan (baterai) → Izinkan.
  4. Tekan Izinkan tampil di atas aplikasi lain → aktifkan untuk Amarella Alarm (supaya layar alarm muncul sendiri).
  5. Tekan TES ALARM: harus berbunyi terus sampai ditekan HENTIKAN ALARM.
Setelah itu biarkan saja. Di bilah notifikasi ada tulisan "Amarella Alarm aktif": artinya aplikasi sedang menjaga PO. Jangan dimatikan dari daftar aplikasi.

Saat ada PO

Layar oranye "PO BARU: SMC" muncul dan alarm berbunyi terus. Tekan Hentikan & buka Amarella untuk langsung menerima PO, atau HENTIKAN ALARM. Alarm juga berhenti sendiri kalau PO sudah diterima dari device lain. PO berikutnya akan berbunyi lagi.

Merek tertentu (Xiaomi, Oppo, Vivo, Realme) punya penghemat baterai tambahan: buka Setelan → Aplikasi → Amarella Alarm → Baterai → pilih Tanpa batasan, dan aktifkan Mulai otomatis.
