🔔 Suara khas notifikasi PO

Ini bunyi alarm yang sama dengan di dalam aplikasi Amarella. Pasang sebagai suara notifikasi aplikasi Amarella supaya PO dari outlet tetap terdengar khas walau aplikasi ditutup.

⬇ Unduh suara (MP3)

Kalau tidak bisa diunduh, tekan lama tombol di atas lalu pilih Download link / Unduh link.

Cara memasang di tablet / HP Android

  1. Unduh suaranya (tombol hijau di atas).
  2. Buka aplikasi File / My Files, cari Amarella PO.mp3 di folder Download, lalu pindahkan / salin ke folder Notifications (di penyimpanan internal).
  3. Buka Setelan → Aplikasi → Amarella → Notifikasi. Kalau tidak ada aplikasi Amarella: Setelan → Aplikasi → Chrome → Notifikasi → Situs lalu pilih amarellapatisserie.github.io.
  4. Ketuk kategori notifikasinya → Suara → pilih Amarella PO. (Samsung: ketuk + / Tambah untuk memilih file dari penyimpanan.)
  5. Aktifkan juga Tampil di layar / Pop-up, dan kalau ada Abaikan Jangan Ganggu.
  6. Naikkan volume notifikasi tablet.

Coba dari aplikasi: menu PO dari outlet → Kirim notifikasi percobaan, lalu tutup aplikasinya.
